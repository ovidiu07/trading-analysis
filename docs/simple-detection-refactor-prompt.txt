CONTEXT
-------
File: backend/src/main/resources/pine/prod/devtrader-chart.pine
Symptom: stats row shows "Det 46 | Val 0 | Pend 0 | Ent 0". Sweeps are being
qualified (Det ticks up) but nothing ever reaches validation. The current
validation path has too many tight wick/ATR/grace-window filters stacked in
series, and any one of them failing silently discards the whole setup.

Chart reality: red/cyan dots on the chart are already the confirmed pivots
(minorHighPivotPrices / minorLowPivotPrices / majorHighPivotPrices /
majorLowPivotPrices at lines 1740-1746). Those ARE the liquidity the indicator
should hunt. The existing LTF MSS engine (f_ltfEntrySignals at ~2252 and its
helpers f_ltfBullMssTime / f_ltfBearMssTime) already detects lower-timeframe
structure shifts and returns entry prices. Nothing downstream uses that output
as a first-class validation signal today.


GOAL
----
Replace the validation path with a dead-simple 4-stage pipeline:

    1. LIQUIDITY GRAB    price takes out a recent swing-high / swing-low pivot
    2. REJECTION         price closes back through the swept level within N bars
    3. LTF MSS           the lower-timeframe MSS engine confirms the reversal
    4. ENTRY             trade goes live on the LTF MSS price

No rejection tier, no chart-timeframe BreakA/B/C/D zoo, no confirmation-swing
ATR leg, no execution-model selection. The LTF MSS price IS the entry.

Keep existing HTF bias block, existing stop model (sweep extreme), and the
existing f_tradeTargetPrice target resolver unchanged.

Keep the existing stats columns (Det, Val, Pend, Ent, Res, W, L, BE, Blk) and
the existing webhook/alert payloads. This refactor only swaps the INTERNAL
logic that moves a setup from Det -> Val -> Pend -> Ent.


NEW PIPELINE SPECIFICATION
--------------------------

STAGE 1 — LIQUIDITY GRAB (Det)

    Trigger (short side, BSL sweep):
        current bar high >= most recent eligible pivot-high price
        AND that pivot-high was confirmed at least `swingLen` bars ago
        AND the pivot price is within last `sweepLookbackBars` bars (default 300)
        AND no active trade, no active waitS

    Trigger (long side, SSL sweep): mirror on pivot-low.

    Eligible pivot source (in this priority):
        majorHighPivotPrices -> majorLowPivotPrices (HTF bubbles)
        minorHighPivotPrices -> minorLowPivotPrices (LTF bubbles)
        Fall through from major to minor if no major within lookback.

    Depth filter (soft): reject pivots whose distance from current price is
    more than `sweepMaxDepth * ATR * 3` away (so we don't fire on ancient
    out-of-range pivots).

    On fire:
        waitS / waitL := true
        waitStartBar*, waitStartTime*, waitSweepLevel*, waitStopAnchor*
        setupsDetectedCount += 1
        structureStatus := "Bearish pivot sweep @ <price>" / mirror long

STAGE 2 — REJECTION (binary, no tiers)

    Grace window: `rejectGraceBars` = 8 bars (was 1-3 in legacy code).

    Success condition (short):
        within rejectGraceBars after waitStartBarS,
        any bar prints: close < waitSweepLevelS
        (the bar that swept is allowed to qualify as its own rejection — so
         a same-bar sweep+close-back counts)

    Failure condition (short):
        current high > waitStopAnchorS + atrVal * sweepMaxDepth
        OR bars_since_sweep > rejectGraceBars without any bar closing back
        inside. Failure resets wait state (no Val increment, no Blk increment).

    Long side: mirror.

    On success:
        set waitRejectedS / waitRejectedL := true
        DO NOT increment Val here. Val only happens at Stage 3.

STAGE 3 — LTF MSS CONFIRMATION (Val)

    Inputs already computed:
        ltfEntryTfValid, ltfEntryTf  (auto-selected lower timeframe)
        ltfBullMssTime, ltfBearMssTime  (last MSS event time on that TF)
        ltfBullEntryPrice, ltfBearEntryPrice  (MSS swing price)

    Short validation:
        waitS AND waitRejectedS
        AND ltfEntryTfValid
        AND not na(ltfBearMssTime)
        AND ltfBearMssTime >= waitStartTimeS
        AND not na(ltfBearEntryPrice)

    Long validation: mirror with Bull.

    On fire:
        waitStructureConfirmedS / L := true
        waitExecModel* := "LTF_MSS"
        waitExecEntry*  := ltfBearEntryPrice / ltfBullEntryPrice
        waitStructureBreakType* := "LTF_MSS"
        setupsValidatedCount += 1
        structureStatus := "Bearish LTF MSS confirmed" / mirror

    Timeout: if no LTF MSS within `mssWaitBars` = 20 bars after rejection,
    reset wait state silently.

STAGE 4 — ENTRY (Ent)

    Trigger (short):
        waitStructureConfirmedS AND not active AND not na(waitExecEntryS)
        AND high >= waitExecEntryS            (price has touched the MSS price)
        AND risk valid: waitStopAnchorS > waitExecEntryS

    Trigger (long): mirror.

    Filters (these still block):
        blockLongEntry / blockShortEntry  (HTF bias block, line 568-569)
        blockLong/ShortLiquidityConflict  (line 3574-3575) — keep as-is

    Remove: shortMsEntryBlock / longMsEntryBlock  (Conservative bias gate)

    On fire:
        entriesTriggeredCount += 1
        active := true
        activeEntryPrice := waitExecEntry*
        tSL := waitStopAnchor*  (sweep extreme + existing stop model)
        t10 := f_tradeTargetPrice(bull, entry, stop)  (unchanged)
        Reset wait state.

CHANGE 1 — Add new simple sweep detector
Location: insert as a new helper near line 2020 (just before
f_selectConfirmationSwing), or anywhere above line 2975.

    // Returns [sweepPrice, sweepBar, sweepTier] for the most recent pivot
    // the current bar just took out. Side: "BSL" = pivot high, "SSL" = pivot low.
    f_detectPivotSweep(string side) =>
        float hitPrice = na
        int   hitBar   = na
        string hitTier = ""
        float ref = side == "BSL" ? high : low
        int minBar = bar_index - sweepLookbackBars

        // Try major pivots first
        array<float> majorArr = side == "BSL" ? majorHighPivotPrices : majorLowPivotPrices
        array<int>   majorBarArr = side == "BSL" ? majorHighPivotBars : majorLowPivotBars
        if array.size(majorArr) > 0
            for i = array.size(majorArr) - 1 to 0
                float p = array.get(majorArr, i)
                int   b = array.get(majorBarArr, i)
                if b < minBar
                    break
                if not f_isConfirmedPivot(b)
                    continue
                bool taken = side == "BSL" ? ref >= p and high[1] < p : ref <= p and low[1] > p
                if taken
                    hitPrice := p
                    hitBar := b
                    hitTier := "MAJOR"
                    break

        // Fall through to minor pivots
        if na(hitPrice)
            array<float> minorArr = side == "BSL" ? minorHighPivotPrices : minorLowPivotPrices
            array<int>   minorBarArr = side == "BSL" ? minorHighPivotBars : minorLowPivotBars
            if array.size(minorArr) > 0
                for i = array.size(minorArr) - 1 to 0
                    float p = array.get(minorArr, i)
                    int   b = array.get(minorBarArr, i)
                    if b < minBar
                        break
                    if not f_isConfirmedPivot(b)
                        continue
                    bool taken = side == "BSL" ? ref >= p and high[1] < p : ref <= p and low[1] > p
                    if taken
                        hitPrice := p
                        hitBar := b
                        hitTier := "MINOR"
                        break
        [hitPrice, hitBar, hitTier]
